# Órbita — Quiz de exploración espacial

Órbita es un cuestionario interactivo en español con 10 preguntas sobre el espacio. Incluye comentarios sobre las respuestas, seguimiento del progreso y una puntuación final. La interfaz se adapta al tema claro u oscuro del sistema y no necesita dependencias.

## Ejecutar en local

Abre `index.html` directamente en un navegador. No hace falta instalar nada ni iniciar un servidor.

## Publicación

GitHub Actions publica el sitio en GitHub Pages cada vez que se actualiza la rama `main`. El workflow también se puede ejecutar manualmente desde la pestaña **Actions** del repositorio.
